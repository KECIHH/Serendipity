# Serendipity · 际遇 项目宪法

本文件由 Phase000 建立，适用于本项目 V1。产品范围依据 `roadmapRoot/docs/product-requirements.md`，字段、状态与执行依据为相应 run 固定的 manifest、canonical contract、术语表、状态机和 Agent-only 契约。用户明确要求优先；项目根和本地开发文档的 Git 边界以根 `AGENTS.md`、`docs/project-layout.json` 为准。派生规范不得扩大产品范围，不静默改写历史输入 hash。

## 项目定位

Serendipity · 际遇 是面向中文用户、以中国境内自由行为主要场景的个人旅行规划工具，定位固定为自然语言优先、AI 主导、JSON 结构化。

用户通过自然语言提出旅行需求，经必要追问获得有来源、可核验、可修改、可分享、可导出的结构化行程。AI 承担需求理解、候选规划与表达；确定性服务承担事实核验、稳定 ID、日期时间、路线、金额、权限、状态迁移和保存资格。产品不承诺实时库存、实时票价和预订成功。

产品展示名固定为 `Serendipity · 际遇`，中点两侧各一个空格；英文名为 `Serendipity`，中文名为 `际遇`。npm 包名及新产品 ASCII 应用标识固定为 `serendipity`；执行包内部工具标识保持兼容，不用于品牌展示。

## 核心原则

- 后台配置优先。非密钥系统配置由受控 `SystemConfig` 管理；Prompt、模型、Provider、规划策略采用不可变版本和明确激活指针，变更经过服务端权限检查、CAS 和审计。
- 不硬编码 API Key、模型名、Prompt 正文和系统配置。密钥只通过受控录入与秘密引用使用，不进入源码、客户端、Git、日志、截图、导出和公共响应，也不向管理员读回明文。
- 事实必须有来源与时间。公开事实经 Provider 校验形成不可变快照；缺失信息明确为 unknown、估算和待核验，不由 AI 补造坐标、价格、时刻或开放时间。
- 结构化数据只有一份权威正文，正式版本追加不可变。用户有效修改产生新版本；失败、取消、无变化和并发冲突不得留下正式版本。
- 权限和隐私由服务端执行。用户只访问自己的记录；公开分享只读且默认关闭，绑定明确的已确认版本。管理员权限不隐式授予用户私有数据的访问权。
- 产品失败透明且可恢复。地图是增强层，地图失败仍保留完整文字行程；AI、Provider、媒体和导出失败不得破坏已有计划。产品用户的选择、确认和同意必须通过真实产品交互表达。

## AI 输出规则

- 内部旅行需求、旅行方案和 AI 任务结果必须使用 JSON；先解析，再按对应 Schema 和确定性业务规则校验，前台页面只展示校验后的结构化数据。
- 正式保存前校验引用完整性、路线与时间可行性、预算、来源、信息时效和质量。precise 仅保存 `pass`；quick 的 `needs_review` 必须无硬违规、降级获策略允许、假设清晰可见，并阻止不满足条件的执行动作。正常规划的 `fail` 不保存正式版本。
- AI 调用统一经过 Provider 抽象和已激活的不可变 `PromptVersion`，冻结同一次调用的模型、Provider、策略版本及预算；不得绕过已注册配置自行调用模型。
- AI 不能决定权限、事实真伪、坐标、金额、状态迁移、保存资格和发布资格。AI 文案不得改写确定性校验结果。
- 失败记录安全分类、request/trace 标识和版本引用；对外不泄露系统 Prompt、API Key、内部堆栈和私人原文。未经校验的原始 JSON、流式片段和调试 trace 不能作为正式行程展示。

## V1 范围

- 自然语言需求理解、quick/precise 模式、统一需求准入和必要追问；每次最多展示三条问题，完整缺失清单继续参与准入判断。
- 有来源的旅行事实与结构化计划：逐日时间轴、跨点交通、住宿、餐饮、景点、摄影、预算、天气、风险、备选、准备清单与信息时效，配套可信地图增强和完整文字降级。
- 计划工作台与生命周期：局部修改、锁定和显式解锁、并发控制、版本历史、Diff、恢复、确认、复制后重新核验、只读归档。
- 匿名临时记录、Credentials 注册登录、可撤销会话、显式匿名合并、个人记录列表、收藏、质量反馈及反馈同意撤回。
- 绑定已确认版本的只读分享、过期、撤销和显式换发；分享与独立公开发布分开授权，公开字段遵循最小白名单。
- 固定版本的 PDF 与 Markdown 导出，个人数据导出与重新认证后的数据擦除；导出权限、中文字体、来源和时效保持一致。
- 管理后台：用户、Prompt、模型、Provider、策略、系统配置、公告、媒体、审计、指标和故障诊断。文件与公开内容具备隔离、扫描、授权、许可和撤下边界。
- 可恢复后台任务、可复现镜像、隔离部署、备份恢复、kill switch、自动发布检查、合成 canary 与回滚。路线最终交付范围为 `LOCAL_RELEASE_READY`，开发验收使用合成数据和隔离服务。

## V1 不做事项

- 订单与预订：不提供机票、酒店、门票、餐厅的下单、库存锁定和代用户联系商家。
- 支付与交易：不提供支付、退款和交易履约。
- 社交：不提供 feed、关注、评论、私信和多人协同编辑。
- 第三方登录：不提供第三方 OAuth 登录。
- 实时导航、车辆或人员跟踪、实时交通控制，以及价格、班次一定有效的承诺。
- 绕过网站条款、验证码、登录墙和禁止再分发限制的数据抓取。
- 由 AI 自行决定事实、权限、状态、正式保存和发布资格。
